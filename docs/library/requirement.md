# 书香海安图书馆服务应用需求文档

> 文档状态：待视觉稿确认  
> 版本：1.0  
> 更新日期：2026-09-17  
> 产品形态：移动端 H5，全栈真实数据应用

## 1. 项目概述

“书香海安”是面向海安市民的移动端图书馆服务应用，整合馆藏发现、借阅续借、图书预约、座位预约、阅读活动、阅读计划和分馆服务信息。

首版以可完整运行、可持续部署为目标，不采用仅在前端生效的演示数据。业务数据保存在 PostgreSQL，图书封面、活动图片等文件保存在 MinIO，前后端通过真实 API 通信。本地使用 Docker Compose 提供 PostgreSQL 和 MinIO，后续仅迁移基础服务，不更换业务数据源或对接第三方图书馆系统。

## 2. 产品目标

1. 让游客无需登录即可发现馆藏、阅读活动和分馆信息。
2. 让已登录读者快速完成续借、图书预约、座位预约和活动报名。
3. 用“海安共读”和地方文献内容体现城市阅读文化，而不是只做工具型借阅系统。
4. 覆盖完整的正常、空、冲突、失败和权限状态，形成可信的公共文化服务体验。
5. 遵循现有 App Portfolio 的模块注册、认证、统一 API、Prisma、文件存储和测试规范。

## 3. 用户与权限

### 3.1 游客

游客可以：

- 浏览首页内容、馆藏、图书详情、活动和分馆信息。
- 使用馆藏搜索、筛选和排序。
- 查看座位余量，但不能提交预约。
- 查看阅读专题和活动回顾。

游客进行收藏、加入想读、续借、图书预约、座位预约、活动报名或阅读打卡时，应进入登录流程。登录完成后返回原页面，并继续原操作上下文。

### 3.2 已登录读者

已登录读者可以：

- 查看读者证、当前借阅、历史借阅和消息。
- 续借符合规则的图书。
- 预约暂时无库存的图书并查看排队状态。
- 预约、取消和签到阅览座位。
- 收藏图书、维护想读和阅读状态。
- 报名、取消和签到阅读活动。
- 设置年度阅读目标并记录阅读打卡。

### 3.3 管理端

首版不建设图书馆后台管理界面。分馆、馆藏、座位和活动基础数据通过 Prisma seed 初始化；必要的数据维护可在后续独立建设。

## 4. 产品导航与页面范围

应用地址为 `/library`，底部使用五栏导航：

1. 首页
2. 馆藏
3. 服务
4. 活动
5. 我的

详情、搜索结果、预约、报名、消息等页面通过栈式页面进入，不占用底部导航位置。

### 4.1 首页“书香海安”

首页按“今天能读什么、能做什么”组织，内容顺序如下：

1. 品牌标识“书香海安”、当前分馆和消息入口。
2. 馆藏搜索，支持书名、作者和 ISBN。
3. 城市阅读主题视觉，体现海安公共阅读氛围。
4. 快捷服务：借阅码、我的借阅、图书续借、座位预约。
5. 个人提醒：即将到期、逾期、预约到书或活动开始提醒；游客显示登录/办证引导。
6. “今日一书”重点推荐。
7. “海安共读”当月主题书单和阅读进度。
8. 最近阅读活动，显示时间、地点、剩余名额和报名状态。
9. 新书与热门馆藏，可按分馆切换。
10. 身边的图书馆，显示开放状态、地址、开放时间和特色设施。
11. 公告和服务指南。

首页唯一高优先级行动为“搜索馆藏”，其他服务保持次级视觉权重。

### 4.2 馆藏

#### 搜索与浏览

- 支持书名、作者、ISBN、出版社关键词搜索。
- 支持搜索历史和热门搜索词。
- 分类包括文学、少儿、历史、社会科学、自然科学、科技和地方文献。
- 筛选条件包括分馆、分类、可借状态和出版年份。
- 排序包括综合、热门、最新出版和距离最近。
- 搜索结果显示封面、书名、作者、分类、可借数量和最近可借分馆。
- 无结果时显示纠错词、相近书目和分类推荐。

#### 图书详情

- 展示封面、书名、作者、出版社、出版年份、ISBN、简介和目录摘要。
- 展示分馆馆藏：分馆、楼层、区域、索书号、总册数和可借册数。
- 馆藏状态包括可借、借出、预约中和仅馆内阅览。
- 支持收藏、加入想读和分享。
- 有库存时提示到馆借阅，不提供线上锁书。
- 无库存时允许选择取书分馆并提交预约。

#### 图书预约

- 显示预约分馆、当前排队位置、预计等待时间和到书保留期限。
- 支持取消尚未到书的预约。
- 同一读者不能重复预约同一图书。
- 有可借库存时不允许创建排队预约。
- 到书后生成消息，超过保留期限自动失效。

### 4.3 服务

#### 当前借阅与续借

- 借阅卡显示封面、借阅日期、到期日期、剩余天数和续借状态。
- 支持单本续借和批量续借。
- 续借前明确展示新的到期日期。
- 存在他人预约、超过续借次数、图书已逾期或读者证异常时不可续借。
- 续借成功后即时更新到期时间、续借次数和操作记录。
- 临近到期使用琥珀色提醒，逾期使用克制的错误色提示。

#### 图书预约管理

- 查看排队中、待取书、已完成、已取消和已失效预约。
- 查看排队位置、预计可取时间和取书期限。
- 支持取消允许取消的预约。

#### 座位预约

- 流程为：选择分馆 → 日期 → 时段 → 楼层/区域 → 座位 → 确认。
- 座位类型包括普通席、设备席和无障碍席。
- 座位图显示可选、已占、不可用和已选状态。
- 提交前展示签到时间、取消规则和违约规则。
- 预约成功后生成签到码和分馆位置说明。
- 支持预约签到、结束使用和按规则取消。
- 同一用户同一时间只能存在一个有效座位预约。
- 同一座位同一时段不能被重复预约。

#### 分馆服务

- 展示地址、联系电话、开放时间、开放状态和设施标签。
- 提供办证指南、借阅规则和常见问题。
- 首版不接入真实地图导航，只展示地址和位置描述。

### 4.4 阅读活动

#### 活动发现

- 顶部展示当月主题，如“秋日共读季”。
- 分类包括读书会、亲子阅读、名家讲座、展览和公益课堂。
- 支持按日期、分馆、适龄人群和是否有名额筛选。
- 提供列表和日历两种查看方式。
- 活动卡显示时间、地点、剩余名额和报名状态。

#### 活动详情与报名

- 展示主题图片、活动介绍、嘉宾、流程、适龄范围、地点和参与须知。
- 支持报名、候补和按规则取消报名。
- 报名成功后生成电子凭证和签到码。
- 支持活动签到和活动结束后的回顾内容。
- 覆盖满员、截止、重复报名和取消超时状态。

#### 阅读挑战

- 首版只设置“2026 海安共读计划”。
- 用户可设置年度阅读目标。
- 图书阅读状态包括想读、在读和读完。
- 每日打卡记录阅读时长和简短感想。
- 展示已读数量、连续阅读天数和本月进度。
- 首版不建设积分商城或复杂徽章体系。

#### 城市文化内容

- 海安共读主题书单。
- 海安地方文献和地方作者专题。
- 分馆特色空间介绍。
- 城市阅读活动回顾。

未核实的真实机构数据、政府通知、嘉宾和统计数字不得作为事实展示。开发阶段使用明确的演示内容，正式上线前替换并审核。

### 4.5 我的

#### 游客状态

- 展示登录和绑定读者证入口。
- 保留本地搜索历史和最近浏览。

#### 读者中心

- 展示姓名脱敏信息、读者证状态、有效期和借阅二维码。
- 展示当前借阅、图书预约、座位预约和活动报名摘要。
- 提供收藏、想读、阅读记录和历史借阅入口。
- 展示“2026 海安共读计划”进度和阅读打卡入口。
- 家庭读者证首版只预留展示位置，不建设复杂监护授权流程。

#### 消息中心

- 消息类型包括到期、逾期、预约到书、座位签到、活动提醒和系统公告。
- 支持已读/未读筛选、单条已读和全部已读。
- 业务消息可跳转至对应图书、预约、座位或活动页面。
- 首页只展示高优先级提醒，完整消息进入消息中心。

## 5. 核心业务规则

### 5.1 续借

- 每笔借阅默认最多续借一次。
- 默认续借周期为 30 天，从当前到期日向后延长。
- 逾期、已达续借次数、读者证异常或该书存在有效排队预约时拒绝续借。
- 续借接口必须以当前数据库状态重新校验，不依赖前端展示状态。

### 5.2 图书预约

- 只有无可借馆藏的图书可以创建预约。
- 同一用户和图书最多一个有效预约。
- 排队顺序按创建时间确定。
- 预约状态包括 `queued`、`ready`、`fulfilled`、`cancelled`、`expired`。

### 5.3 座位预约

- 时间段使用明确的开始、结束时间和 Asia/Shanghai 时区。
- 数据库必须防止同一座位同一时间段出现两个有效预约。
- 用户不能创建时间重叠的有效预约。
- 状态包括 `reserved`、`checked_in`、`completed`、`cancelled`、`missed`。

### 5.4 活动报名

- 报名人数不得超过活动容量。
- 满员后进入候补队列。
- 同一用户不能重复报名同一活动。
- 状态包括 `registered`、`waitlisted`、`checked_in`、`cancelled`。

## 6. 数据与媒体要求

- PostgreSQL 是所有业务数据的唯一事实来源。
- Prisma migration 管理数据结构变更，Prisma seed 提供可体验的初始数据。
- MinIO 保存图书封面、活动主图、专题图片和分馆图片。
- 数据库只保存文件引用，不保存二进制内容。
- 公开展示媒体通过现有文件服务读取，并遵守文件访问权限。
- 种子数据至少覆盖成功、空、即将到期、逾期、不可续借、排队、满员和预约冲突状态。

## 7. 非功能需求

### 7.1 兼容与响应式

- 移动优先，最小支持宽度 320px。
- 在现有最大 760px 的 H5 容器中正常显示。
- 所有触控目标至少 44px。
- 不允许移动端横向滚动。
- 正确处理顶部和底部安全区。

### 7.2 性能

- 首页聚合接口避免前端发起大量串行请求。
- 列表使用分页；默认每页 20 条，上限 100 条。
- 图片提供稳定尺寸，避免页面布局跳动。
- 搜索输入使用防抖，且旧请求不得覆盖新结果。

### 7.3 可访问性

- 正文和背景对比度满足 WCAG AA。
- 交互控件提供可读标签、焦点状态和禁用原因。
- 状态不能只依赖颜色表达。
- 动效遵循 `prefers-reduced-motion`。

### 7.4 安全与一致性

- 所有写接口要求认证，并从访问令牌读取用户身份。
- 用户只能访问和修改自己的借阅、预约、收藏、报名和消息。
- 参数使用现有校验层验证。
- 座位预约、活动名额和续借使用事务保证一致性。
- 接口沿用 `{ code, message, data }` 统一响应格式。

## 8. 首版不包含

- 图书馆后台管理系统。
- 真实支付和逾期费用结算。
- 实体借书设备、门禁或 RFID 集成。
- 真实地图、短信、微信服务通知。
- 第三方图书馆业务系统对接。
- 跨馆物流和线上锁定可借图书。
- 积分商城、复杂徽章和社交评论社区。

## 9. 验收标准

1. 应用可从应用市场进入 `/library`，并具备五栏主导航。
2. 游客可完成馆藏、活动和分馆浏览；受保护操作会触发登录。
3. 登录读者可完成续借、图书预约、座位预约、活动报名、收藏和阅读打卡。
4. 所有业务操作经过真实 API，并在 PostgreSQL 中持久化。
5. 图书封面和活动图片从 MinIO/文件服务加载。
6. 刷新页面后业务状态保持一致，多请求冲突由服务端正确拒绝。
7. 页面覆盖加载、空、错误、无权限、冲突和成功状态。
8. 前端 lint/build、后端 check/test 和新增业务测试通过。
9. 视觉实现遵循 `design.md`，并与确认后的视觉稿一致。
