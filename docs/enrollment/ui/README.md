## 已落实的关键约束

- 首页不设置底部 TabBar 和消息入口。
- 学校列表不展示当前状态、剩余名额或资格预测。
- 学校政策确认后先进入数据预处理页，查询共享数据再进入时间轴。
- 时间轴只展示学生、家庭及户籍、房产及居住、材料上传四个信息簇。
- 时间轴节点使用与信息预览一致的分组样式，支持折叠查看数据；折叠箭头控制展示，“修改”进入独立编辑页面。
- 预览提交为独立长页面，不属于时间轴节点。
- 部门数据只用于辅助填写，是否符合招生条件由学校老师审核。
- 学生信息不采集性别、出生日期和民族。
- 初审通过不等于最终录取，不设置“未录取”状态。
- 公开查询只展示脱敏身份和必要结果信息。

## 第二版调整

- 学校政策确认后增加数据预处理，集中完成学生查询条件、授权和共享数据查询。
- 学生完整信息回到时间轴对应的独立编辑页补充。
- 时间轴缩减为四个信息簇，仅展示摘要；箭头进入独立编辑页面。
- 家庭及户籍合并为一个信息簇，条件性信息并入材料上传。
- 信息预览与提交改为独立、自然高度的长页面。
- 时间轴延续原版紧凑样式并展示完整摘要，预览页面采用手机单列布局，设计图只展示正常比例首屏，后续内容自然下滑查看。
